# JS · Entrega de ejercicios 1

Nueve ejercicios de JavaScript vanilla, cada uno con su HTML y su JS por separado, y una página de índice.

```
index.html
js_ejercicio_1.html + js_ejercicio1.js   Cambiador de color de fondo
js_ejercicio_2.html + js_ejercicio2.js   Contador de clics
js_ejercicio_3.html + js_ejercicio3.js   Lista dinámica
js_ejercicio_4.html + js_ejercicio4.js   Filtro de búsqueda en tiempo real
js_ejercicio_5.html + js_ejercicio5.js   Calculadora sencilla
js_ejercicio_6.html + js_ejercicio6.js   Temporizador
js_ejercicio_7.html + js_ejercicio7.js   Generador de contraseñas
js_ejercicio_8.html + js_ejercicio8.js   Contador de palabras y caracteres
js_ejercicio_9.html + js_ejercicio9.js   Lista de tareas con localStorage
styles.css                               Estilos comunes
```

## Ver en local
Abre `index.html` en el navegador (no necesita servidor ni dependencias).

## Publicar en GitHub Pages
1. Crea un repositorio nuevo y sube estos archivos a la rama `main`.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
3. La URL pública será `https://<tu-usuario>.github.io/<repositorio>/`.
